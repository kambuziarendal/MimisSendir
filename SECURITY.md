# Security reports

Please use [private vulnerability reporting](https://github.com/kambuziarendal/MimisSendir/security/advisories/new), not public issues, for security-sensitive reports.

Beta 5 is the current client. Historical betas are archived for recovery and are not actively maintained. Never include credentials, QR codes, real conversation text or private media URLs in a public report.

See [security and privacy](docs/public/SECURITY-PRIVACY.md), including the Signal bridge trust boundary.
